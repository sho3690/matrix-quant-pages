    Rules

    ルール どう選び、いつ入り、いつ出るか

    ① 決算サプライズ

    決算の利益が、事前に専門家が予想していた数字をどれだけ上回ったか。良い驚きのあと、株価は数週間〜2か月かけてじわじわ上がり続ける傾向が知られています(決算後ドリフト)。

    Bernard & Thomas (1989) / Meursault et al. (2023)

    ② 経営陣の自信

    決算説明会や決算短信の「言葉」を点数化。前向きで言い切る表現が多い説明ほど、その後の株価が良い傾向があります。数字が良くても語り口が弱気なら割り引きます。

    Meursault, Liang, Routledge & Scanlon (2023) "PEAD.txt"

    ③ 取引先の追い風

    大口の取引先(親会社・主要顧客)の株価が先に上がると、約1か月遅れて下請け・素材メーカーの株価も追いつく傾向があります。「取引先は上がったのに、この会社はまだ」という銘柄ほど高得点です。

    Cohen & Frazzini (2008) "Economic Links and Predictable Returns"

    • 選ぶ3つの点数を合計した「合成スコア」の上位5%が候補。3つ点灯 ＞ 2つ点灯 ＞ 1つ点灯の順に優先し、1つも点灯していない銘柄は選ばない(70点以上を「点灯」と呼ぶ)。
    • 入る候補を確認した翌営業日の寄り付きが目安。決算発表から日が浅いほど良く、45営業日を過ぎた銘柄は見送る。
    • 持つ60営業日(約3か月)。研究で報告されたドリフトはこの期間で頭打ちになる。
    • 出る次のどれかが先に来たら手じまい: ①60営業日が経過 ②次の決算発表の前日 ③更新後にスコアが50未満に低下 ④取引先の株価が急落。
    • やらない1銘柄に集中しない(研究の効果は複数銘柄の平均)。損切りの幅(例: 買値から−8%)は買う前に決めておく。この画面は投資助言ではなく、最終判断は自分で行う。
    もっと詳しく(専門家向けの定義)

    Ring A — 標準化予想外利益(SUE)

    SUE_i,q = (EPS_actual − EPS_consensus) / P_{i,t0−1} … アナリスト基準(価格スケーリング) SUE^SRW_i,q = (ΔEPS_q − mean ΔEPS_{q−1..q−8}) / std ΔEPS_{q−1..q−8}, ΔEPS_q = EPS_q − EPS_{q−4} → 四半期ごとの横断面パーセンタイルランクへ落とし、十分位(decile)・三分位(tercile)に分割。

    day 0 は「市場が最初に反応できる営業日」(15:00 JST 以降の発表は翌営業日)。Ring A は直近イベントのランクを 60 営業日で線形減衰させて 0–100 に写像します。

    Ring B — テキスト由来サプライズ(SUE.txt)

    φ(text) = [tone, certainty, forward, numeric, finbert] tone = (pos − neg)/(pos + neg + 1), certainty = (certain − uncertain)/(certain + uncertain + 1) SUE.txt = 2·P̂(surprise > 0 | φ) − 1 ∈ [−1, 1] … L2 ロジスティック回帰(Newton–Raphson) (ラベル付きテキスト < 30 件のときは事前重みによる線形合成を tanh 変換)

    日本語は Loughran–McDonald 型の金融極性辞書を日本語開示語彙へ写像したもの、英語は transformers があれば FinBERT(ProsusAI/finbert)の P(pos)−P(neg) を特徴量に追加します。

    Ring C — 顧客モメンタムとリード・ラグ

    CM_i,t = Σ_j w̃_ij · r̃_j,t w̃: 売上依存度を正規化した顧客ポートフォリオ重み、r̃: 市場調整リターン ρ̄(k) = Σ_(i→j) w_ij · corr(r_i,t, r_j,t−k) / Σ w_ij, k* = argmax_{k≥1} ρ̄(k) … 波及ラグ r_i,t+1 = α_t + β_t·CM_i,t + γ_t·r_i,t + δ_t·MOM_i,(t−12,t−2) + ε … Fama–MacBeth, Newey–West t gap_i = z(CM_i) − z(r̃_i) … 過小反応ギャップ Ring C = 100·(0.6·pct(CM) + 0.4·pct(gap))

    PEAD イベントスタディと合成

    CAR_i[+2,+61) = Σ (r_i,τ − r_m,τ) 市場調整(TOPIX 連動 ETF 1306)、60 営業日 条件表: SUE 三分位 × SUE.txt 三分位 の平均 CAR・勝率・n。「最良条件」= n ≥ 20 で平均 CAR 最大のセル 合成 = Σ w_k·Ring_k / Σ w_k(利用可能リングのみ、w = 0.40 / 0.25 / 0.35)+ 3 リング全達成ボーナス 8 候補 = 合成スコア上位 5%(最低 5 銘柄)
